# 年会抽奖系统 (Lucky Draw System)

基于 Vite + Vue 3 + Pinia + Arco Design 开发的纯前端年会抽奖系统。

## ✨ 功能特性

*   **🎈 氛围感强**: 红色喜庆主题，支持自定义背景图，烟花庆祝特效。
*   **⚡️ 简单易用**: 纯前端实现，无后端依赖，数据存储在本地浏览器。
*   **📊 管理便捷**:
    *   **Excel 导入**: 批量导入员工名单（支持 `xlsx` 格式）。
    *   **奖项配置**: 灵活设置奖项名称、图片、数量。
    *   **数据导出**: 抽奖结果一键导出 Excel。
*   **🛡️ 数据安全**:
    *   自动去重（已中奖人员不会再次中奖）。
    *   数据持久化（刷新页面不丢失）。
    *   防误触设计（空格键控制，重置数据需确认）。

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```
打开浏览器访问显示的地址（如 `http://localhost:5173`）。

### 3. 构建生产版本

```bash
npm run build
```
构建产物位于 `dist` 目录，可直接部署到任何静态文件服务器。

## 📖 使用指南

1.  **初始化设置**:
    *   进入 `/admin` 管理后台。
    *   **导入人员**: 在“人员管理”中上传 Excel 文件（列名需包含：`姓名`、`工号`、`部门`）。
    *   **设置奖项**: 在“奖项管理”中添加或修改奖项。
2.  **进行抽奖**:
    *   返回首页 `/`。
    *   切换奖项，设置本轮抽取人数。
    *   按 **空格键 (Space)** 开始/停止抽奖。
3.  **查看结果**:
    *   中奖后自动弹窗展示。
    *   可在后台“抽奖记录”中查看并导出名单。

## 🛠️ 技术栈

*   **框架**: Vue 3, Vite
*   **UI**: Arco Design Vue
*   **状态管理**: Pinia + pinia-plugin-persistedstate
*   **工具**: XLSX (Excel处理), canvas-confetti (烟花特效)
