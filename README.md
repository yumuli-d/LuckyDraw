# 年会抽奖系统 (Lucky Draw System)

基于 Vite + Vue 3 + Pinia + Arco Design 开发的纯前端年会抽奖系统。

## ✨ 功能特性

- **🎈 氛围感强**: 红色喜庆主题，支持自定义背景图，3D 球体人员滚动动画，烟花庆祝特效。
- **⚡️ 简单易用**: 纯前端实现，无后端依赖，数据加密存储在本地浏览器（LocalStorage）。
- **🎮 双模式切换**:
    - **常规模式**: 预设奖项及单次抽取人数，点击奖项精准抽取。
    - **混合模式**: 自动从所有奖项池中随机分配，支持手动设置抽取人数。
- **📊 管理便捷**:
    - **Excel 导入**: 批量导入员工名单（支持 `姓名`、`工号`、`部门` 列）。
    - **奖项配置**: 灵活设置奖项名称、颜色、总数及单次抽取人数。
    - **名单导出**: 中奖结果全屏展示，支持按奖项分组一键导出 Excel。
- **🛡️ 数据安全**:
    - 自动去重（已中奖人员不会再次中奖）。
    - 数据持久化（刷新页面或关闭浏览器不丢失）。
    - 防误触设计（空格键控制开始/停止，重置需确认）。

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

打开浏览器访问显示的地址（如 `http://localhost:5173`）。

### 3. 构建生产版本

```bash
npm run build
```

构建产物位于 `dist` 目录，可直接部署到任何静态文件服务器（如 GitHub Pages, Vercel, Nginx）。

## 📖 使用指南

1.  **初始化设置**:
    - 进入 `/admin` 管理后台。
    - **导入人员**: 在“人员管理”中上传 Excel 文件。
    - **设置奖项**: 在“奖项管理”中添加或修改奖项及单次抽取人数。
    - **模式选择**: 在“全局设置”中切换抽奖逻辑模式。
2.  **进行抽奖**:
    - 返回首页 `/`。
    - 按 **空格键 (Space)** 或点击按钮开始/停止抽奖。
3.  **查看结果**:
    - 中奖后实时展示中奖人卡片。
    - 点击右下角“查看全部名单”可全屏浏览并导出 Excel。

## 🛠️ 技术栈

- **框架**: Vue 3 (Composition API), Vite
- **UI**: Arco Design Vue
- **状态管理**: Pinia + pinia-plugin-persistedstate
- **工具**: XLSX (Excel处理), canvas-confetti (烟花特效), dayjs (时间处理)
